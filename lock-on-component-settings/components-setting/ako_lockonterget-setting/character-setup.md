# Character Setup

#### The <mark style="color:orange;">**Character Setup**</mark> <mark style="color:orange;"></mark><mark style="color:orange;">section</mark> contains two settings that allow the Lock-On Target system to identify which **Camera** and **Spring Arm** it should use on your character.

#### <mark style="color:$success;">Camera Index</mark>

**Use this setting to specify which Camera the Lock-On system should use.**

If your character contains multiple Cameras, enter the index of the Camera you want the system to use.

* **0** — First Camera
* **1** — Second Camera
* **2** — Third Camera
* And so on.

#### <mark style="color:$success;">Spring Arm Index</mark>

**Use this setting to specify which Spring Arm the Lock-On system should use.**

If your character contains multiple Spring Arms, enter the index of the Spring Arm you want the system to use.

* **0** — First Spring Arm
* **1** — Second Spring Arm
* **2** — Third Spring Arm
* And so on.
