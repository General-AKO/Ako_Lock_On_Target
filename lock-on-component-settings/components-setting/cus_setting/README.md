# cus\_setting

> #### **The `Cus_Setting` component provides&#x20;**<mark style="color:$success;">**additional**</mark>**, target-specific settings that allow you to customize how an&#x20;**<mark style="color:$success;">**individual target**</mark>**&#x20;behaves within the Lock-On system.**

Its settings are divided into three main sections:

#### <mark style="color:violet;">1- Character Setting</mark>

**Contains settings related to the target's character and its skeletal setup used by the Lock-On system.**

#### <mark style="color:violet;">2- General Setting</mark>

**Contains general settings that customize the behavior and properties of the individual target.**

#### <mark style="color:violet;">3- UI Target Info</mark>

**Contains settings used to customize the information and visual elements displayed for the target, such as its Target Icon and target-related UI.**
