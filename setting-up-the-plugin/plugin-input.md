# plugin input

#### **The Lock-On Target system supports both&#x20;**<mark style="color:blue;">**Keyboard & Mouse**</mark>**&#x20;and&#x20;**<mark style="color:$success;">**Gamepad**</mark>**&#x20;input.**

The system includes several Input Actions used to control the Lock-On system and interact with its targeting features.

These Inputs are divided into <mark style="color:$success;">**two**</mark> groups:

<mark style="color:green;">**Core Inputs**</mark> <mark style="color:green;"></mark><mark style="color:green;">—</mark> These are the essential Inputs required to control the Lock-On system and its target switching functionality.

<mark style="color:cyan;">**Demo Inputs**</mark> <mark style="color:cyan;"></mark><mark style="color:cyan;">—</mark> These Inputs are included specifically for the provided demo setup and are not required for the core Lock-On system to function.

### <mark style="color:purple;">Core Inputs</mark>

You can find the required Inputs in the <mark style="color:$success;">**`MC_lock_on_Input`**</mark>.

#### <mark style="color:blue;">**1- IN\_lockOn**</mark>

**Use this Input to activate or deactivate the Lock-On system.**

It works as a toggle:

* Press it once to activate **Lock-On** and select a target.
* Press it again while Lock-On is active to cancel the current Lock-On and **Unlock** the target.

In other words, the same Input is used to both **Lock-On** and **Unlock target.**

#### <mark style="color:blue;">2- IN\_Up\_Change</mark>

**Use this Input to switch the current target upward.**

#### <mark style="color:blue;">3- IN\_Down\_Change</mark>

**Use this Input to switch the current target downward.**

#### <mark style="color:blue;">4- IN\_Left\_Change</mark>

**Use this Input to switch the current target to the left.**

#### <mark style="color:blue;">5- IN\_Right\_Change</mark>

**Use this Input to switch the current target to the right.**

#### <mark style="color:yellow;">**These four directional Inputs work together to let you manually move between available targets while Lock-On is active.**</mark>

#### <mark style="color:blue;">**6- IN\_HIDE/SHOW UI**</mark>

**Use this Input to hide/show the ui target.**
