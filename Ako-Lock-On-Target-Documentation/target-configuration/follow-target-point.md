# Follow Target Point

**Follow Target Point** controls how the target UI relates to the target point.

## Enabled

The UI follows the exact target point currently being used by the lock-on setup. That can include:

- A custom target height.
- A specific bone.
- The currently selected bone in a bone-switching setup.

## Disabled

The UI remains positioned using the actor's center rather than following target-point changes.

## Choosing the behavior

Use **Enabled** when the information panel should track the selected body point.

Use **Disabled** when the lock-on point and the information panel should deliberately have different positional behavior.
