# Context-Sensitive Settings

The editor intentionally hides or disables settings that do not apply to the currently selected mode.

## Target-point settings

Bone-specific options appear when a bone-based target-point mode is selected.

## World UI settings

World-space transform options appear only in configurations that support World UI placement.

## Status settings

Status-specific configuration appears when **Status Widget** is selected.

## Segmented settings

**Segment Count** applies to **Custom Progress Bar**.

## Text settings

Description text settings appear when **Text** is selected as the display style.

## Why the editor behaves this way

This context-sensitive workflow reduces conflicting combinations and keeps the Details panel focused on settings that currently matter.
