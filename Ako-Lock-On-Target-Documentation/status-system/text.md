# Status & Description Text

Status Elements expose dedicated text configuration for text-based target information.

## Status Text

The Status Text configuration includes:

- Text
- Text color
- Font

It can be used for values or labels such as:

```text
Health
Stamina
Shield
Rage
Poisoned
```

The runtime content can be driven by your Blueprint/UI logic.

## Description Text

When **Display Style** is set to **Text**, additional description settings become available:

- Description Text
- Description Text Color
- Description Text Font
- Auto Wrap Text

## Auto Wrap Text

Enable Auto Wrap Text when the description may be wider than the available widget area.
