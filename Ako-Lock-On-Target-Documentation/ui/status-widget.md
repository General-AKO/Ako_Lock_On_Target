# Status Widget

Choose **Status Widget** when you want the built-in status-oriented workflow.

The Data Asset uses **Status Widget Class** for this workflow.

## Typical uses

- Health
- Stamina
- Shield
- Rage or another resource
- Status text
- Several status values displayed together

## Status Widget Alignment

**Status Widget Alignment** controls the placement of status content.

Available values:

- Center
- Top
- Bottom
- Left
- Right

## Background and border

When the status presentation uses the panel-style display mode, you can configure:

- **Background Color**
- **Border Color**

## Important behavior

The built-in Status Widget is forced to **Screen** widget space by the plugin. If another widget-space value is entered for a Status Widget, the plugin automatically corrects it.
