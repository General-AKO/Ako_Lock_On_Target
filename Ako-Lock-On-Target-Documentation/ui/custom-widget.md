# Custom Widget

Choose **Custom Widget** when you want your own Widget Blueprint to control the visual design.

In this workflow, the Data Asset references the widget through **Info Widget**.

## Use Custom Widget when you need

- A completely custom target design.
- Custom animations.
- Additional gameplay information.
- Project-specific interactions.
- UI layouts that do not fit the built-in status workflow.

## Basic workflow

1. Create the Widget Blueprint.
2. Set the Data Asset's **Widget Type** to **Custom Widget**.
3. Assign the Widget Blueprint to **Info Widget**.
4. Configure UI mode and placement.
5. Assign the Data Asset to the target actor.

Your Widget Blueprint remains responsible for the visual implementation and project-specific runtime behavior.
