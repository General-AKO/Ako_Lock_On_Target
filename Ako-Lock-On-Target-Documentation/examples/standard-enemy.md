# Standard Enemy

A simple enemy normally needs only the default target point and a reusable UI definition.

## Configuration

1. Add the Lock-On Target component.
2. Assign the enemy Skeleton when bone features are required.
3. Keep Target Point on **Default**.
4. Assign the default Lock On Icon.
5. Create `DA_Target_Enemy`.
6. Choose Custom Widget or Status Widget.
7. Assign the Data Asset to the target.
8. Test the target in game.

This is the simplest setup and avoids bone switching until it is actually needed.
