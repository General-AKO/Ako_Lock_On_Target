# Segmented Health

Create a segmented health indicator with the built-in Status Widget workflow.

## Configuration

1. Set Widget Type to **Status Widget**.
2. Add a Status Element.
3. Select **Custom Progress Bar** as the Display Style.
4. Set **Segment Count** to the number of visual units you want.
5. Assign a suitable **Progress Bar Image**.
6. Configure Fill Color and size.
7. Adjust Noise Opacity and Noise Strength when needed.

For example:

```text
Segment Count = 10
```

The ten segments are purely visual. The underlying gameplay percentage remains independent from the number of segments.
