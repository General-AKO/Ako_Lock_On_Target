# Custom Target UI

Use **Custom Widget** when the built-in Status Widget does not match the desired design.

## Workflow

1. Create your Widget Blueprint.
2. Set the Data Asset's Widget Type to **Custom Widget**.
3. Assign the widget class to **Info Widget**.
4. Configure UI mode and placement.
5. Assign the Data Asset to the target actor.

This approach is appropriate for custom layouts, special animations, additional gameplay information, and project-specific interaction logic.
